# Frieren Portfolio

A single-page personal portfolio themed on *Frieren: Beyond Journey's End*, built for CC107 Activity 4 (Application Development: Web Platforms).

**Live site:** https://ray-xxv.github.io/portfolio-activity/

## Features
- Four sections: Header / Navigation, Hero / About Me, Projects, Footer / Contact
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive layout with CSS Grid and Flexbox, plus `@media` queries for tablets and phones
- **Day / Night mode toggle** (main JavaScript feature), remembered between visits
- Hamburger menu on mobile, smooth scrolling, and active-section highlighting in the nav

## Files
| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content |
| `style.css` | Colors, typography, layout, hover effects, responsive rules |
| `script.js` | Theme toggle, mobile menu, nav highlighting |
| `images/profile.jpg` | Profile photo |

## Run locally
Open `index.html` in any modern browser. No build step is needed.
